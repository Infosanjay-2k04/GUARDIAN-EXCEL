Guardian Excel is an AI-powered safety system designed for predictive monitoring and real-time threat detection across multiple safety tiers. This repository contains the mobile app (Expo/React Native), monitoring utilities, and a Streamlit dashboard for live visualization.

## What It Does
- Predictive monitoring and threat detection
- Multi-tier escalation and notifications
- Mobile application (Expo) and web dashboard

## Quick Start
1. Install Node dependencies (inside `GuardianApp`):

```bash
cd GuardianApp
npm install
```

2. Start the Expo app:

```bash
cd GuardianApp
npm start
# or
# expo start
```

3. Run the Streamlit dashboard (optional):

```bash
pip install streamlit
streamlit run streamlit_dashboard.py
```

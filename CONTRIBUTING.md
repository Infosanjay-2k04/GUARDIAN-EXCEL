# Contributing

Thanks for your interest in contributing to Guardian Excel. We welcome improvements, bug fixes, and documentation enhancements.

Getting started
- Fork the repository and create a feature branch: `git checkout -b feature/your-feature`
- Make changes and run linters/tests where applicable
- Submit a pull request describing your changes

Guidelines
- Keep changes focused and clearly described
- Write tests for bug fixes and new features when possible
- Update documentation and examples when behavior changes

Communication
- Use issues to discuss large changes before implementation
- Be respectful and follow the `CODE_OF_CONDUCT.md`
